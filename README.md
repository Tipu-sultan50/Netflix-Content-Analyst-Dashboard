# 🎬 Netflix Content Analysis Dashboard

A professional and interactive **Netflix Content Analysis Dashboard** built in **Power BI**. This project analyzes Netflix's content library using interactive visualizations, KPIs, and slicers to uncover trends in movies, TV shows, genres, countries, and release years.

---

## 📌 Project Overview

The objective of this project is to transform raw Netflix data into meaningful business insights through data cleaning, transformation, and interactive visualization.

The dashboard enables users to explore Netflix's content library by filtering data based on content type, country, rating, and month.

- Displays countries with the highest number of Netflix titles.

### 🎭 Top Genres
- Shows the most popular genres available on Netflix.

### 📈 Release Year Trend
- Visualizes content growth over time.

- Displays the distribution of titles by rating.

## 🧹 Data Cleaning

The dataset was cleaned using Power Query by:

- Removing null values
- Renaming columns
- Removing duplicate records
- Standardizing text values
- Formatting data types
- Cleaning country values
- Preparing data for visualization

## 💡 Key Insights

- Movies represent the majority of Netflix content.
- Netflix content has grown significantly over recent years.
- Some countries contribute substantially more titles than others.
- Drama and TV-related genres are among the most common.
- Content ratings vary widely across the catalog.
